# Twitter Bookmark Surveillance

twitter のブックマークをローカルに全て保存  

## 機能

-   ブックマークしたツイートの情報をローカルのdbに記録
-   ツイート本文をテキストファイルとして保存
-   ツイートに含まれる画像/動画をダウンロード

## 認証設定

このツールは、あなたのブラウザのログイン情報 (Cookie) を使用します  
手元環境で認証情報を取得し、それを動作環境（ubuntu server等）に持っていって稼働させる想定です  
そのため、初回のみ以下の手順で認証情報を `auth.json` ファイルとして保存する必要があります  

#### ステップ1: デバッグモードでChromeを起動、twitterにログイン

WSL環境から以下のコマンドを実行すると、ホスト側のchromeが起動します  
（wsl2のnetworkingMode=mirroredである必要あり）  
`https://x.com` にアクセスしてログインを完了させてください  

```bash
bash scripts/run_wslhost_chrome.sh
```

#### ステップ2: 認証情報の保存

Xにログインした状態を保ったまま、**別の新しいターミナルを開き**、プロジェクトディレクトリで以下のコマンドを実行します  

```bash
tsx src/saveAuth.ts
```

ターミナルに「ログインが完了したら、このWSLターミナルでEnterキーを押してください」と表示されます  
指示に従ってEnterキーを押すと、プロジェクトのルートに `auth.json` ファイルが生成されます  
これにて認証設定は完了です  

## 実行

以下のコマンドを実行すると、ブックマークの取得と保存が開始されます  

```bash
cp .env.example .env
docker compose up
```

## 保存先

取得したツイートのデータは、プロジェクト内の `bookmarks` ディレクトリに保存されます  

-   テキスト: `(ツイートID)_(日付)_.txt`
-   画像: `(ツイートID)_(日付)_(番号).jpg` など
-   動画: `(ツイートID)_(日付)_video.mp4`
